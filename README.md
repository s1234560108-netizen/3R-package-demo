# 3R-package-demo

A Python package for Session 1 of the 3R course.

Author: Shao Chien Chang

## Installation

```bash
python -m pip install -r requirements.txt
python -m pip install -e ".[test]"
```

## Usage

```bash
three-r "  hello  "
```

## Testing

```bash
python -m pytest
```
